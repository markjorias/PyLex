A comprehensive technical reference for the PyLex engine and Python's lexical grammar.

What can PyLex do?

The ultimate toolkit for Python syntax decomposition.

bolt

Real-time Analysis

Experience sub-millisecond tokenization as you type. Our Flex-based engine processes code streams instantly, providing immediate feedback.

account_tree

Structural Tracking

Unlike basic highlighters, PyLex tracks Python's significant whitespace, emitting INDENT and DEDENT tokens to visualize block structure.

The Dictionary

Every token type supported by our Flex specification.

Keywords

RESERVED
"def" | "if" | "async" | "await" | "lambda"

Core reserved words that define the structural control flow and logic of Python programs.

Identifiers

NAMING
[a-zA-Z_][a-zA-Z0-9_]*

User-defined labels for variables, functions, and classes. Must start with a letter or underscore.

Numbers

LITERALS
INT: 0x123 | FLOAT: 3.14e-10 | COMPLEX: 5j

Full support for integers (hex, bin, oct), floating point with scientific notation, and imaginary numbers.

Strings

LITERALS
f"text", r"raw", """triple""", b"bytes"

Supports single, double, and triple quotes with prefixes for raw, formatted, and byte strings.

Constants

BUILT-IN
True | False | None

Dedicated recognition for Python's core logical constants and the null representation.

Structure

BLOCKS
INDENT | DEDENT

Emitted tokens based on leading whitespace (spaces or tabs), mapping Python's visual block hierarchy.

Operators

SYMBOLS
+, -, **, //, ==, !=, +=, >>=, :=

Comprehensive set of mathematical, logical, and assignment operators, including walrus and power.

Delimiters

SYMBOLS
":", "->", "...", "[", "]"

Syntax-level delimiters, separators, and type-hinting arrows used in Python grammar.

Comments

INFO
#.*

Captured as tokens for structural analysis, these annotations provide developer context within the code.

Errors

LEXICAL
. (Catch-all)

Characters that do not match any known Python token pattern are flagged for manual review.

The Engine Lifecycle

How your code becomes data.

01

Raw Stream

The source code is ingested as a continuous stream of characters into our compiled C binary.

02

Regex Scan

Finite State Automata match the longest possible patterns against our optimized Flex specification.

03

JSON Emission

Matched tokens are mapped to JSON objects and piped back to the UI for color-coded visualization.
